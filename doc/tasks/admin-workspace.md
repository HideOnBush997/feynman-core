# 管理员工作区

## 最小任务

- [x] 建立管理员路由与工作区导航；未授权用户不能进入管理员页面。
- [x] 实现租户列表、创建、详情和停用界面，呈现启停状态及操作反馈。
- [x] 实现账号列表、创建管理员/标注员、标注员租户绑定和账号停用界面。
- [x] 实现任务草稿创建和编辑表单，校验名称、说明、HTTP/HTTPS 视频 URL 和 Shanghai 截止时间输入。
- [x] 实现草稿发布；发布后刷新任务状态并锁定任务基本信息编辑入口。
- [x] 实现管理员对可领取/已领取任务的取消、对已领取任务的收回操作，并反馈冲突状态。
- [x] 实现已提交任务退回和待修正任务改派操作；明确展示原标注员和当前负责人。
- [x] 实现每日统计日期筛选和总有效时长展示。
- [x] 实现统计逐层展开，展示租户、标注员、任务及已提交片段明细。
- [x] 为列表加载、空结果、API 错误、成功操作和分页提供一致反馈。
- [x] 编写管理员关键操作组件测试，并联调管理员 API 契约。

## 完成条件

- 所有写操作依赖后端授权和状态响应，不由前端状态自行裁决。
- 已提交任务不能取消；待修正状态不能取消；退回后的原片段保留并可改派。
