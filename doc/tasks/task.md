# Task（任务管理）

## 最小任务

- [x] 建立任务实体、任务状态、领取人、截止时间、版本字段及 EF Core 映射。
- [x] 实现管理员创建草稿、编辑草稿和取消草稿；校验名称 1–200、说明最多 4000、HTTP/HTTPS URL 最多 2048 字符。
- [x] 实现管理员发布草稿；发布后锁定基本信息并进入可领取状态。
- [x] 实现管理员按权限分页查询任务及详情，支持租户、状态和截止时间筛选。
- [x] 实现标注员仅查询所属启用租户的可领取任务和本人任务。
- [x] 实现原子领取，验证任务可领取、用户/租户启用且归属一致；并发时至多一人成功。
- [x] 实现标注员退回未提交任务，原子清理领取关系并恢复可领取状态。
- [x] 实现管理员收回已领取未提交任务，原子清理领取关系并恢复可领取状态。
- [x] 实现管理员取消可领取或已领取未提交任务；已领取取消时同一原子操作解除分配。
- [x] 实现逾期标记派生；逾期任务仍允许领取和提交。
- [x] 实现管理员退回后默认原标注员修正、管理员可改派；保留已有片段并更新领取关系。
- [x] 使用条件更新/事务实现状态竞争裁决，覆盖取消/收回与保存/提交竞争。
- [x] 测试状态转换、跨租户访问拒绝、并发领取、版本冲突和取消限制。

## 完成条件

- 已提交任务不可取消；待修正任务不可取消；收回只作用于未提交的已领取任务。
- 管理员收回/取消先成功时后续标注保存/提交被拒；提交先成功时只能走管理员退回流程。
