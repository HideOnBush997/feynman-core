# Account（账号管理）

## 最小任务

- [x] 建立用户扩展字段、角色、启停状态和可空租户关联的 EF Core/Identity 映射。
- [x] 实现用户名规范化：去除首尾空白、长度 1–50、大小写不敏感全局唯一，不额外限制字符集。
- [x] 实现仅平台管理员可创建管理员账号和标注员账号；标注员必须绑定启用租户。
- [x] 实现临时密码设置和首次登录必须改密的账号标记。
- [x] 实现账号停用，保留历史记录并撤销其 Refresh Token。
- [x] 提供管理员分页查询账号及其角色、租户和状态。
- [x] 为输入验证、用户名冲突、停用和权限失败提供稳定 Problem Details 业务码。
- [x] 测试用户名规范化/唯一性、角色/租户约束、停用历史保留和刷新令牌撤销。

## 完成条件

- 管理员不能绕过服务端规则创建无租户标注员或重复用户名。
- 停用账号不能登录、刷新或继续执行受保护业务请求。
