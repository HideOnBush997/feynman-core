# Tenant（租户管理）

## 最小任务

- [x] 建立租户实体、启用状态和 EF Core 映射。
- [x] 实现仅平台管理员可用的租户分页列表、详情和创建 API。
- [x] 实现租户停用 API，保留租户及其任务、账号、统计历史。
- [x] 在认证/授权上下文中提供租户启用状态检查，阻止停用租户用户登录和继续操作。
- [x] 为租户 API 应用角色策略并返回统一 Problem Details 错误。
- [x] 测试管理员授权、创建/查询/停用、历史保留及停用租户用户操作拒绝。

## 完成条件

- 标注员不能读取或修改其他租户信息；请求中的租户 ID 不作为授权依据。
- 停用只阻止后续登录和业务操作，不删除历史数据。
