- [x] 查询并展示本人已领取、待修正及已提交任务，支持查看任务详情。

- [x] 实现提交确认和提交结果反馈；成功后刷新状态并锁定片段编辑入口。
- [x] 为列表加载、空状态、错误、截止/逾期、领取和提交结果提供反馈。
