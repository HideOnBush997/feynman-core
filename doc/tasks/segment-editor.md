# 片段编辑器

## 最小任务

- [x] 建立片段数据模型，以非负整数毫秒表示起止时间，并按起点升序显示。
- [x] 实现添加片段表单，支持从当前播放位置带入起点/终点并可精确编辑毫秒值。
- [x] 实现片段修改和删除；每次变更通过片段 API 立即持久化。
- [x] 显示片段列表、单段时长和任务片段总时长。
- [x] 基于已知视频时长提供即时范围提示；时长不可用时展示边界未验证提示。
- [x] 展示服务端验证反馈：起点小于终点、无负值、不可重叠、完全重复禁止、首尾相接允许。
- [x] 根据任务状态锁定提交后编辑；待修正任务加载保留的原片段并允许修改。
- [x] 实现至少一个有效片段才允许提交的交互提示；服务端仍为最终校验者。
- [x] 编写片段增改删、排序、总时长、错误反馈和锁定状态的组件测试。

## 完成条件

- 时长未知时不误报边界已验证，仍呈现服务端返回的其他校验错误。
- 提交成功后片段内容锁定；管理员退回后保留内容可修正。
