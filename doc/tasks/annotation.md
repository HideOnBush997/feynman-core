# Annotation（片段标注）

## 最小任务

- [x] 建立片段实体和稳定 ID，以非负整数毫秒保存起止时间，并添加数据库唯一约束/索引。
- [x] 实现仅当前领取人可读取任务片段；管理员可按管理权限读取。
- [x] 实现新增片段 API，并验证操作者租户、领取关系和任务可编辑状态。
- [x] 实现修改和删除片段 API；以任务版本/并发令牌避免静默覆盖。
- [x] 每次片段变更立即持久化；提交锁定和待修正状态规则在服务端执行。
- [x] 实现统一片段校验器：起点小于终点、非负、完全重复禁止、互不重叠且首尾相接允许。
- [x] 在请求提供有效视频时长时验证片段终点不超过时长；时长未知时仅跳过边界校验。
- [x] 实现按起点升序返回片段及版本冲突的明确响应。
- [x] 测试零长度、倒置、负值、重叠、相邻、重复、视频边界已知/未知和并发版本冲突。

## 完成条件

- 所有授权和业务校验由后端执行，不能依赖前端传入租户 ID 或本地校验。
- 保存阶段与提交阶段共享相同的片段有效性规则。
