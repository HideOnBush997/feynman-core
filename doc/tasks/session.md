# 会话模块

## 最小任务

- [x] 建立前端会话状态模型，定义匿名、已登录、需首次改密和加载中状态及转换测试。
- [x] 实现登录表单与登录 API 调用，处理凭据错误、停用账号、首次改密要求和加载/失败反馈。
- [x] 将 Access Token 仅保存在内存，并提供供 API 客户端读取和更新的令牌接口。
- [x] 实现刷新 Cookie 会话恢复；页面初始化时使用 credentials 调用刷新端点并恢复 Access Token。
- [x] 合并同一时刻的并发刷新请求，登出时调用服务端撤销并清理内存会话。
- [x] 实现首次登录修改临时密码流程；成功后更新会话状态并进入相应工作区。
- [x] 编写会话状态转换、刷新恢复、并发刷新合并、登出和首次改密组件/单元测试。

## 完成条件

- Access Token 不写入 localStorage、sessionStorage 或持久化状态。
- 刷新失败后清除会话并回到登录界面；失败原因有清晰反馈。
- 无有效会话时受保护页面不可进入；角色只影响导航体验，后端仍负责授权。
