# Submission（提交与退回）

## 最小任务

- [x] 实现标注员提交 API，检查任务状态、领取人、启用账号/租户和片段版本。
- [x] 在单一事务中校验至少一个有效片段及全部片段规则，成功后记录最近提交人/时间并转换为已提交。
- [x] 提交成功后锁定片段；重复或过期版本提交返回明确冲突。
- [x] 实现管理员退回已提交任务，原片段保留、转换为待修正且立即退出有效统计。
- [x] 支持待修正任务重新提交，按当前片段重新校验并记录新的成功提交时间。
- [x] 与 Task 模块状态转换协调，确保提交与管理员取消/收回的并发结果原子且一致。
- [x] 为提交校验失败、权限失败、状态冲突提供 Problem Details 和稳定业务码。
- [x] 测试空片段拒绝、提交后锁定、退回保留、重新提交和取消竞争原子性。

## 完成条件

- 只有成功提交且当前状态为已提交的任务可成为统计输入。
- 退回后原提交暂不计入；重新提交后只以新提交时间和当前片段参与统计。
