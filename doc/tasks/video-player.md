# 视频播放器

## 最小任务

- [x] 封装使用 `HTMLVideoElement` 播放任务公开视频 URL 的播放器组件，不经由应用后端代理。
- [x] 暴露播放、暂停、当前播放时间及跳转到指定时间的操作。
- [x] 读取媒体元数据，在可获得时将视频 duration 转为整数毫秒并通知片段编辑器。
- [x] 在元数据不可用、duration 非法或播放失败时提供明确提示，并报告边界未验证。
- [x] 提供可替换媒体元素的测试边界，覆盖时长可用、不可用和播放错误。
- [x] 验证播放器向片段编辑器传递的时间精度为毫秒，不进行时区转换。

## 完成条件

- 外部视频源失败不阻断任务页面其他信息显示。
- 无法取得时长时提示视频边界未能校验，提交仍由后端执行其余规则校验。
